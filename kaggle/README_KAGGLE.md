# Jais Voice — النشر على Kaggle 🎙️

## المتطلبات
- حساب Kaggle مجاني
- GPU: **T4 ×2** (مجانًا في Kaggle)
- Internet: **ON** (الافتراضي مغلق!)

## الخطوات (5 دقائق)

1. افتح [kaggle.com](https://www.kaggle.com) → **Create** → **New Notebook**
2. من اللوحة الجانبية (Settings):
   - **Accelerator** = `GPU T4 ×2`
   - **Internet** = `ON`
3. **File → Import Notebook** → ارفع `kaggle/jais_voice_kaggle.ipynb`
4. **Run All** (السهم فوق) — واتركها تنفذ
5. عند خلية `4) نفق عام` تظهر لك 👇
   ```
   🔗 رابطك العام: https://xxxx-xxxx.trycloudflare.com
   ```
6. افتح الرابط من **أي جهاز** (هاتف/لابتوب) — HTTPS جاهزة
7. اضغط **اتصال** ثم **🎙️ تحدث** واسأل بالعربي، الوكيل يُسمعك ويجاوبك بصوت

## كيف يعمل

```
ميكروفون متصفحك (WebM/Opus)
  → WebSocket عبر النفق
  → faster-whisper (ASR, CPU)
  → Jais-3-7B (T4×2, bf16→fp16 auto)
  → edge-tts (صوت عربي سعودي)
  → رد صوتي في متصفحك
```

- كود المشروع يُستنسخ تلقائيًا من GitHub داخل الخلية 3 — لا حاجة لرفع ملفات.
- ASR: `faster-whisper` — يُزمّر نماذجه تلقائيًا أول مرة (~500MB).
- LLM: `inception42/Jais-3-7B` — يُحمّل من HuggingFace؛ لو النموذج مقيد، أضف HF_TOKEN في CONFIG.
- TTS: Microsoft Neural (مجاني، بلا مفتاح) — صوت Hamed عربي سعودي افتراضيًا.

## حدود Kaggle (كن واقعيًا)

| البند | القيمة |
|---|---|
| أقصى مدة GPU session | 12 ساعة متواصلة |
| حصة أسبوعية | ~30 ساعة GPU |
| حجم الذاكرة GPU | 2× 15GB (إجمالي ~30GB — يكفي Jais-3-7B via `device_map=auto`) |
| الرابط العام | **يغيّر مع كل جلسة** (لا ثابت) |
| الزوار | الرابط عام — أي شخص يملكه يدخل |

> **التشغيل الثاني:** عند رجوعك للسيرفر وإعادة Run All، ستحصل على رابط جديد — هذا طبيعي مع الحساب المجاني. لمشروع مؤسسي احترافي استخدم توكن ngrok مدفوع أو انتقل لخادم حقيقي (RunPod/GPU محلي).

## استكشاف الأخطاء

**1. "فشل cloudflared — استخدم خلية ngrok الاحتياطية"**
→ Kaggle أحيانًا يحجب UDP. الحل: خلية ngrok الاحتياطية مع `NGROK_TOKEN` مجاني مِن [dashboard.ngrok.com](https://dashboard.ngrok.com/get-started/your-autotoken).

**2. أول رد يستغرق 1–2 دقيقة**
→ طبيعي — النموذج يُتحمّل ويُجذّر في الذاكرة. المكالمات اللاحقة أسرع (2–8 ثوانٍ للرد الكامل).

**3. الميكروفون لا يعمل**
→ تأكد أن الرابط HTTPS (تلقائي من cloudflared) وأن أعطت إذن المتصفح. Chrome / Edge أفضل.

**4. الصوت بين الوكيل يقطع أو بطئ**
→ Kaggle على GPU مشترك وليست بنية إنتاج. هذا جيد للتجربة والعرض، وحسّنوه:
   - خفّف `ASR_SIZE` إلى `base` أو `tiny`
   - أو استخدم `LLM_MODEL` أصغر (مثلاً Jais-family-2B من HF)

**5. الرابط فُقد بعد تصفح طويل**
→ أعد Run للخلية `4) نفق عام` فقط وستحصل على رابط جديد.

## الأدوار والحسابات

| وضع التشغيل | ASR | LLM | TTS | مناسب |
|---|---|---|---|---|
| Kaggle (الافتراضي) | faster-whisper small | Jais-3-7B (transformers fp16) | edge-tts | تجربة/عرض تقديمي |
| Kaggle محسّن | faster-whisper base | Jais-family-2B أو أصغر | edge-tts | رد أسرع (~3–5s) |
| RunPod/خادم حقيقي | Jais-ASR | Jais-3-7B FP8/vLLM | SILMA TTS | **الإنتاج الفعلي** |

## مسار التسيير المؤسسي

- جرّب Kaggle للتطوير والعرض التقديمي للعملاء
- عند 3+ عملاء حقيقيين → اترك Kaggle وانتقل مباشرة إلى RunPod / خادم A100 حقيقي (بـ 3–16 ألف ريال شهريًا)
